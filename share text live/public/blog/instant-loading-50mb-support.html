Instant Text Loading & 5MB File Support

Feature UpdateAugust 2026

We've completely overhauled the synchronization engine behind Shareli to prioritize speed above all else.

The Problem with Large Files

Previously, if a room contained large files (e.g., 5MB), joining the room required downloading the entire room history before you could see any messages. For users on slower networks, this meant staring at a blank screen for several seconds.

Streaming History & Skeleton Loaders

Today, we've fixed this. We introduced a new Streaming History engine. When you join a room, Shareli now instantly streams text messages first. Large files are processed asynchronously in the background. While the files are loading, you'll see a beautiful "Skeleton Loader" placeholder so you know exactly what is happening without the page freezing.

This means you can instantly read text and code snippets, even if there is a massive 5MB file currently being downloaded and decrypted in the background.
