Shareli Features: The Complete Guide to Private Text & File Sharing

Shareli was built around one uncompromising idea: sharing text, code snippets, voice notes, and files across devices should be frictionless, instantaneous, and radically private. Here is an in-depth breakdown of every feature built into Shareli.

Overview: The Shareli Philosophy

Most modern communication tools require users to create an account, verify an email or phone number, download bulky native apps, and leave permanent conversation logs on third-party cloud servers.

Shareli flips this model upside down:

  • No Account Required: You never have to sign up, sign in, or provide personal details.
  • Client-Side Encryption: Your data is encrypted in your device's browser before transmission.
  • RAM-Only Storage: There is no SQL database, MongoDB, or permanent disk storage. When messages expire or processes restart, data is permanently destroyed.

Detailed Feature Breakdown

🔐

1. End-to-End Encryption (E2EE)

Uses native browser WebCrypto API with AES-GCM 256-bit keys. Every message gets a fresh 12-byte cryptographically secure random Initialization Vector (IV). The host server only ever sees encrypted ciphertext.

💬

2. Live Typing Previews

Watch characters appear live as peers type via real-time WebSockets. Perfect for fast-paced collaboration, collaborative editing, or reviewing text transfers without manual page refreshes.

📎

3. Multi-File & Image Sharing

Drag and drop multiple files (PDFs, ZIPs, documents, images) up to 5MB. Includes batch upload tracking and an interactive Lightbox preview with zoom, copy, and download actions.

🎤

4. Encrypted Voice Notes

Record audio messages directly in your browser. Audio streams are encrypted on the client side before upload and feature clean inline waveform playback with self-destruct capabilities.

⏱️

5. Self-Destructing Message Timers

Set message lifetimes for 10 seconds, 30 seconds, 2 minutes, 10 minutes, or Keep (up to 6 hours). When a timer expires, the payload is immediately purged from server memory.

📱

6. Instant QR Code Room Sync

Pair your mobile phone with a desktop or tablet in under two seconds. Shareli generates an on-screen QR code and includes a built-in camera scanner for lightning-fast room joining.

🔒

7. Password-Protected Rooms

Add an optional passphrase to your private rooms. The encryption key is derived client-side using PBKDF2 with SHA-256 and 100,000 iterations, making brute-force cracking virtually impossible.

📋

8. Markdown & 190+ Language Syntax Highlighting

Format messages with Markdown headings, lists, quotes, and links. Paste code in JavaScript, Python, Dart, Rust, Go, SQL, HTML, or C++ with automatic syntax coloring and a one-click copy button.

📌

9. Message Pinning

Pin crucial instructions, links, or code blocks to the top banner of the room. Pinned messages stay locked to the top of the viewport so connected participants never lose sight of them.

✏️

10. Live Edit & Delete

Fix typos on the fly. Authors can edit or delete their own sent messages in real time. Room administrators can moderate the wall and delete unauthorized messages.

📥

11. Room Export (.TXT & .MD)

Need to save your session before closing the browser? Export the entire room's message history as a formatted plain text (.txt) or Markdown (.md) document with one click.

📲

12. Progressive Web App (PWA)

Install Shareli directly to your macOS Dock, Windows Taskbar, iPhone Home Screen, or Android App Drawer for a native app feel with zero app store downloads.

Public Rooms vs. Private Rooms vs. Password Rooms

Shareli provides three distinct room modes depending on your privacy requirements:

1. The Public Room

Similar to an open IRC channel or a public community text wall. The public room is open to anyone visiting the site. It uses a shared static key for convenience and is intended for general testing, casual discussions, and public broadcasts. Do not post sensitive passwords or private files here.

2. Private Rooms (Zero-Knowledge URL Hash)

When you click "New private", a random 256-bit encryption key is generated in your browser and embedded in the URL fragment (#key=...). Because URL fragments are never sent to the server (per RFC 3986), only people who possess the full URL can decrypt the conversation.

3. Password-Protected Rooms

Want to share a room link over an insecure channel without exposing the key in the URL? Create a password-protected room. Both parties must type the agreed password. The browser uses 100,000 rounds of PBKDF2 to derive the exact AES-256 key locally.

Frequently Asked Questions

What makes Shareli different from other text and file sharing tools?

Shareli combines three essential qualities: zero registration (no account or login required), true client-side end-to-end encryption (AES-GCM 256-bit), and real-time live synchronization with auto-destructing timers stored only in server RAM.

Can I use Shareli on my smartphone?

Yes! Shareli is fully responsive and works seamlessly across iOS, Android, macOS, and Windows browsers. You can also install it as a Progressive Web App (PWA) directly to your home screen.

How does Shareli ensure the server cannot read my messages?

In private rooms, the decryption key is located strictly within the URL hash fragment (#key=...). By international internet standards (RFC 3986), URL hashes are processed solely within your browser and are never transmitted to web servers in HTTP or WebSocket headers.
